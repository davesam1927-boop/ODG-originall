# ODG ORIGINA — Fresh Website Starter

A free, mobile-friendly static storefront concept for ODG ORIGINA.

## Files
- `index.html` — complete website
- `assets/odg-model-lookbook.png` — current model lookbook image

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `odg-origina-store`.
2. Upload `index.html`, `README.md`, and the `assets` folder (keep the image inside `assets`).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL it gives you.

This is a static site with WhatsApp ordering, not a payment-processing checkout. No payment details are collected on this page. Confirm stock, shipping, and payment directly with customers. Use final approved product photos before launch.
